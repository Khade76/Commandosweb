# Active routes to use

The new React routing work adds these pages:

- Home: `/`
- About: `/about`
- Companies: `/companies`
- Vanguard: `/companies/vanguard`
- Spectre: `/companies/spectre`
- Spartan: `/companies/spartan`
- Our Servers: `/servers`
- Enlist: `/enlist`
- WARDOGS: `/wardogs`
- Donate: `/donate`

The Our Servers page is wired to `/api/servers` for future live game server data.
