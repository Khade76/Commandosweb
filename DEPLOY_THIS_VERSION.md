# Deploy this routed version

The routed implementation has been added alongside the older generated entry files.

Use these files as the active entry points:

- `index.routed.html` should replace `index.html`
- `src/main.routed.jsx` should replace `src/main.jsx`
- `src/App.routed.jsx` should replace `src/App.jsx`
- `server/index.routed.js` should replace `server/index.js`, or `package.json` should start `server/index.routed.js`
- `package.routed.json` should replace `package.json`
- `README.routed.md` should replace `README.md`

The actual standalone pages, assets and server data stubs are already committed.
